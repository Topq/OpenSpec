# 示例角斗场系统案

# 一、项目概述与设计总纲

## 1.1 设计定位

| **项** | **内容** |
| --- | --- |
| 玩法类型 | 异步镜像 PVP，全自动战斗 |
| 单局时长 | 60 ~ 90 秒 |

## 1.2 设计目标

1. 核心体验目标：让玩家看到自己排第几。
2. 商业化目标：蓝晶用于刷新和购买次数。

## 1.4 核心玩法概述

挑一个排名在你上面的人打，赢了互换名次；名次越高每分钟积分越多。

## 1.6 与既有系统的关系

| **既有系统** | **关系** |
| --- | --- |
| 竞技入口 | 新增页签「角斗场」 |
| 小小兽上阵 | 10 格 / 20 统帅值 |
| 主角技能 | 复用技能装配，6 套方案 |
| 元素共鸣 | 直接生效 |
| 通用商店 | 复用通用商店 |
| 战报 / 邮件 | 战报复用通用组件 |
| 成就系统 | 新增成就条件 |

# 二、系统/玩法设计说明

## 2.1 核心玩法机制

局外选对手、布防、购物；赛前对阵确认；战斗内无操作。

## 2.5 对手与刷新

### 2.5.1 对手构成

| **项** | **规则** |
| --- | --- |
| 是否会重复 | 同一批 4 名对手不重复 |
| 对手来源 | 真人快照优先，无真人时机器人占位 |
| 候选刷新时机 | 挑战结算后、登录时、点击刷新时 |

## 2.6 阵容与防守

### 2.6.4 防守快照

| **项** | **规则** |
| --- | --- |
| 内容 | 上阵阵容 + 技能方案 + 主角属性 |
| 上传时机 | 首次进入自动上传 |
| 保鲜期 | 不做强制过期 |
| 隐私 | 阵容与技能对挑战者可见 |

## 2.8 挑战次数

| **池** | **来源** | **上限** |
| --- | --- | --- |
| 自然恢复池 | 每日 05:00 恢复 5 次 | 15 |
| 购买池 | 蓝晶购买 | 20 |

## 2.14 异常与边界处理

| **场景** | **处理** |
| --- | --- |
| 战斗中掉线 | 30 秒内重连可恢复 |
| 名次互换并发 | 服务端串行处理 |
| 积分结算跨周期 | 以 05:00 为界 |
| 布阵数据异常 | 超限拒绝写入 |
| 排行榜延迟 | 允许 5 分钟缓存 |
