# 过滤与分类规则

规则在 `scripts/filter_rules.py`。本文件解释每条规则的作用，调整时先读这里。

## 1. 整章删除（DROP_H1）

匹配一级标题，命中即删除整章：

| 规则 | 删除内容 |
| --- | --- |
| 美术资源 | 场景、模型、特效、角色生产清单 |
| 音乐/音效/音频 | BGM、音效、语音 |
| 策划配置表/配置表 | 未定稿配置表、服务端数据结构 |

## 2. 小节删除（DROP_H2）

匹配二级标题，命中即删除该小节：

| 规则 | 删除内容 |
| --- | --- |
| 设计目标 | 商业化、留存、系统职能等策划论证 |
| 世界观 | 世界观、美术主题、场景基调 |
| 版本范围/后续规划 | 版本包含/不包含与后续路线 |
| AI 支持/AI 对接 | 自动战斗的后端实现要求 |
| 对手数据来源 | 真人快照/机器人生成逻辑 |
| 服务端数据结构 | 服务端存储结构 |
| 既有表改造 | 既有配置表改造清单 |
| 埋点 | 运营指标 |

## 3. 分类（CATEGORY_RULES）

按一级标题匹配到输出文件：

- 概述/项目概述/定位 → `01-定位与核心循环.md`
- UI/界面/页面 → `04-页面与UI.md`
- 待确认/附录 A → `05-待确认问题.md`
- 名词/附录 B → `06-名词表.md`
- 流程图/附录 C → `07-流程图.md`

含「系统/玩法」的一级标题会按二级标题再拆：

- 命中「次数/结算/奖励/经济/蓝晶/竞技币/战报/排行榜/预览/异常/边界」→ `03-次数与经济.md`
- 其余 → `02-系统规则.md`

未匹配的一级标题进入 `99-其他.md`，不会丢内容。

## 4. 表格行过滤（TABLE_RULES）

按二级标题匹配，支持两种模式：

- `keep`：只保留首列命中关键词的行。
- `drop`：删除首列命中关键词的行。

当前规则：

| 小节 | 模式 | 作用 |
| --- | --- | --- |
| 与既有系统的关系 | keep | 只保留竞技入口、小小兽上阵、主角技能、通用商店、战报/邮件 |
| 防守快照 | drop | 删除内容、上传时机、保鲜期 |
| 异常与边界 | drop | 删除并发、跨周期、名次池、竞技币等服务端行 |
| 对手构成 | drop | 删除「对手来源」行 |
| 待确认 | keep | 只保留保底、商店、名次、界面、入口、文案、展示、倍速、自动视角 |

## 5. 调整方式

- 新增大类：在 `CATEGORY_RULES` 加一行 `(标题正则, 输出文件名, 输出一级标题)`。
- 新增删除章节：在 `DROP_H1` / `DROP_H2` 加正则。
- 新增表格行规则：在 `TABLE_RULES` 加 `{"section": 正则, "keep"/"drop": [关键词]}`。
- 改输出顺序：改 `OUTPUT_ORDER`。

原则：**只删明确知道是干扰的内容，未命中一律保留。** 如果某个新文档的结构与规则不符，先跑一次看输出，再补规则，不要为了删干净而改用 allowlist。
